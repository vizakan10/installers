# ⚡ VIZA CLI
**The AI-Powered Terminal Assistant**

VIZA brings the power of state-of-the-art LLMs directly to your command line. Fast, private, and optimized for Windows.

---

## 🚀 Installation (Recommended)
VIZA is delivered as a portable, pre-compiled binary. No Python or Pip is required.

1. **[Download](https://github.com/vizakan10/installers/releases/tag/viza-v1.0.2)**
2. **Extract the ZIP** to a folder of your choice.
3. Right-click **`install_viza.bat`** and select **"Run as Administrator"**.
4. Restart your terminal and type `viza` to begin.

---

## ✨ Key Features
*   **Viza Chat**: Full interactive AI sessions in your terminal.
*   **Intelligent Fix**: Type `viza up` after any error to get an instant AI solution.
*   **Agentic Mode**: Let VIZA manage files and run shell commands for you.
*   **Lightning Fast**: Compiled native binary starts in milliseconds.

---

## 🗑️ Uninstall
To remove VIZA completely from your system:

**Option A (Terminal):**
Type `viza uninstall` and follow the prompts.

**Option B (Manual):**
Run `uninstall_viza.bat` from your original installation folder.

---

## 📋 What the Installer Does
*   **Binary Placement**: Copies `viza.exe` to `%LOCALAPPDATA%\Viza`.
*   **Path Registration**: Adds this folder to your **User PATH** automatically so you can run `viza` from any folder.
*   **Zero Dependencies**: Does not install Python or any other third-party software.

---

## 🔧 Troubleshooting

| Problem | Fix |
| :--- | :--- |
| **viza not found** | Restart your terminal. PATH changes need a fresh session to take effect. |
| **SmartScreen Warning** | Click "More info" → "Run anyway". (App is not yet signed with a global cert). |
| **Permission Error** | Ensure you are running `install_viza.bat` as an **Administrator**. |
